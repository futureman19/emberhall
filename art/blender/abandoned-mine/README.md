# Hollowvein Diggings

Original deterministic, script-authored low-poly Emberhall abandoned mining landmark. Eight reusable modules plus one assembled landmark. This is isolated static art, not gameplay integration.

## Deliverables
- `emberhall-mine.blend`: named editable mesh parts in nine same-origin collections. Only the sealed-mine-mouth collection is initially visible; toggle collection visibility to edit others. Render studio retained.
- `build_camp.py` and `designs.py`: complete procedural authoring source. Regeneration OVERWRITES generated files and manual edits to the blend. Blender 5.2.1 was used.
- `../../../public/art/abandoned-mine/`: nine GLBs, measured manifest, layout blueprint, locally vendored Three.js gallery and thumbnails.
- `../../verification/abandoned-mine/`: hero, contact sheet, browser captures, independent JSON reports, raw execution logs, preservation baseline and verified source ZIP.

## Modules
`sealed-mine-mouth`, `timber-shoring`, `straight-track`, `broken-track`, `broken-ore-cart`, `tool-rack`, `spoil-heap`, `mining-workbench`.

`hollowvein-diggings.glb` assembles ten module instances, plus an earth skirt, 22 boundary rocks and six five-stalk weed clusters. The cart is deliberately abandoned off the rails; the broken curved track is discarded trackwork, not a snapping railway continuation. Rubble and timber intentionally intersect at the sealed portal. The mine mouth is completely blocked, NOT enterable.

## Coordinates / edit contract
- Source: Blender Z-up. Export: standard glTF Y-up, `(x,y,z)` Blender maps to `(x,z,-y)` glTF.
- Each module collection is authored at local origin, lowest vertex on ground. Source mesh object transforms remain identity; vertices carry the geometry. No lineup offsets.
- Portal fronts point Blender negative Y / glTF positive Z. Track runs along Blender Y / glTF Z; straight rail length 3 units, gauge .9 units.
- Layout translations, scales and Y-axis yaw are glTF coordinates. Instance names prefix source part names. Independent reopened-source audit checks every copied vertex against this layout.
- Units and footprints are provisional visual world units, NOT approved tile occupancy, blockers, sockets or collision.
- Layout JSON reconstructs module placement only. Full prefab also requires assembly-only dressing generated by `assembly()` in `designs.py`.
- Flat colors use named `Palette` corner colors linked into the material. Export copies are joined; source parts remain separately editable.

## Reproduce from repository root
Use a current Blender executable, Node.js with installed `three` and `playwright`, Python with Pillow, and Windows Georgia/Segoe fonts for the presentation sheets. Dependencies are not installed or altered by these scripts.

```text
blender --background --factory-startup --python-exit-code 1 --python art/blender/abandoned-mine/build_camp.py
node art/blender/abandoned-mine/verify.mjs --measure
node art/blender/abandoned-mine/verify.mjs
blender --background art/blender/abandoned-mine/emberhall-mine.blend --python-exit-code 1 --python art/blender/abandoned-mine/verify_source.py -- --present
blender --background art/blender/abandoned-mine/emberhall-mine.blend --python-exit-code 1 --python art/blender/abandoned-mine/verify_assembly.py
python art/blender/abandoned-mine/package_gallery.py
node art/blender/abandoned-mine/browser_verify.mjs
python art/blender/abandoned-mine/verify_scope.py
python art/blender/abandoned-mine/package_delivery.py
```

`node art/blender/abandoned-mine/serve.mjs` serves the standalone gallery at loopback port 8190 (PORT environment override supported). Stop with Ctrl+C. The gallery requires HTTP, not file://, but no CDN or network dependency; vendored Three.js license is included. Browser verification starts an ephemeral loopback server and closes server and Chromium in finally.

## Verification boundaries
Actual Blender execution, independent saved-source reopening, exact blueprint vertex transforms, nine blocked portal sample rays, actual GLTFLoader finite positions/normals/colors, triangle-area tests, Y-up bounds/ground pivots, palette variation, measured file hashes and sizes. Desktop 1440x1050 and emulated touch mobile 390x844 exercise all nine assets, filters, rotate toggle, mouse/touch camera changes, reset button, download SHA256 and error/overflow checks. This is desktop Chromium mobile emulation, NOT a physical phone test. No navigation, collisions, rigid-body support, animation, manifoldness, performance budget or game acceptance is claimed. No NPCs, loot, quests, harvesting, deployment, map integration or persistent server.

Visual refinement moved the cart off the raised rails so its loose wheel and plank sit on dirt; reduced gallery presentation disk; tightened desktop framing; separated mobile status from controls. Final hero and desktop/mobile screenshots were reviewed. Small tools require orbit/zoom for detail. Deep intersections and physical stability are not exhaustively tested.

Source ZIP excludes `.blend1`, `.blend2`, pycache, other ZIPs, and its own inventory. `delivery-inventory.json` verifies every archived file by readback SHA256. Old raw logs remain for provenance; the `*-final.log` files and JSON reports describe the delivered candidate.
